# Changelog

## 0.3.0 - Unreleased

### Added

- RustRover 2025.3.1 plugin scaffold using the IntelliJ Platform Gradle Plugin.
- Dedicated `.rhbs` file type, bicycle icons, template lexer, mixed HTML
  highlighting, brace matching, comments, quote handling, and Live Templates.
- Project-wide language-server integration with a language-service status
  item.
- Safe versioned extraction and SHA-256 validation for bundled native servers.
- Project settings for a custom server path and explicit legacy template
  globs.
- Generated Rust, project reload, and server restart actions.
- Unit tests for platform selection, legacy globs, and incomplete template
  tokenization.
- Universal native packaging, archive inspection, and Plugin Verifier
  workflows.
